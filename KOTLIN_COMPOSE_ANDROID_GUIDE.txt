================================================================================
DERF PQ MESSENGER — 100% VS CODE & COMMAND-LINE BUILD GUIDE (NO ANDROID STUDIO)
Native Kotlin + Jetpack Compose + Chaquopy
================================================================================

You can build, package, deploy, and debug the native Kotlin + Jetpack Compose Android app
100% inside VS Code (Terminal / PowerShell) without ever opening Android Studio!

--------------------------------------------------------------------------------
STEP 1: VS CODE EXTENSIONS FOR KOTLIN & GRADLE
--------------------------------------------------------------------------------
Inside VS Code, install these free extensions from the Marketplace:
1. Kotlin (by mathiasfrohlich / JetBrains)
2. Gradle for Java (by Microsoft)
3. Android (by vscandroid) or Android iOS Emulator (by Mobile Apps)

--------------------------------------------------------------------------------
STEP 2: PREREQUISITES ON YOUR PC
--------------------------------------------------------------------------------
1. Java JDK 17 (Installed on Windows, e.g. Eclipse Temurin JDK 17).
2. Android SDK Command-line Tools (containing `adb.exe` and `sdkmanager`).
   • Add `platform-tools` to your Windows PATH:
     `C:\Users\<YourUsername>\AppData\Local\Android\Sdk\platform-tools`

--------------------------------------------------------------------------------
STEP 3: BUILD THE .APK DIRECTLY IN VS CODE TERMINAL
--------------------------------------------------------------------------------
Open a Terminal in VS Code (`Ctrl + ~`) and navigate to the `android/` directory:

    cd android

Run Gradle to compile the APK directly:

On Windows PowerShell / CMD:
    .\gradlew.bat assembleDebug

On Linux / macOS:
    ./gradlew assembleDebug

Gradle will compile the Kotlin + Compose code, download Chaquopy Python packages,
and generate the installable APK at:
    `android/app/build/outputs/apk/debug/app-debug.apk`

--------------------------------------------------------------------------------
STEP 4: INSTALL & RUN DIRECTLY ON YOUR CONNECTED PHONE FROM VS CODE
--------------------------------------------------------------------------------
1. Connect your Android phone via USB (with USB Debugging enabled).
2. Verify connected device in VS Code terminal:

    adb devices

3. Build, install, and automatically launch the app on your phone in one command:

    .\gradlew.bat installDebug
    adb shell am start -n com.derf.pq/.MainActivity

--------------------------------------------------------------------------------
STEP 5: REAL-TIME LOGCAT LOGGING & DEBUGGING IN VS CODE
--------------------------------------------------------------------------------
To view live Kotlin, Python, and Chaquopy log output directly in your VS Code terminal:

    adb logcat *:S System.out:V stdio:V Python:V AndroidRuntime:E

================================================================================
SUMMARY OF VS CODE COMMANDS:
• Build APK:            `cd android; .\gradlew.bat assembleDebug`
• Install & Launch:     `.\gradlew.bat installDebug; adb shell am start -n com.derf.pq/.MainActivity`
• Live Log Stream:      `adb logcat *:S System.out:V stdio:V Python:V AndroidRuntime:E`

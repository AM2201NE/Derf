CRITICAL STEP TO FIX "No module named 'PyQt6'" ON ANDROID
================================================================================

Why this error happened:
When Briefcase runs `briefcase update android`, it only copies updated Python code.
Because `pyproject.toml` previously had `PyQt6` in its dependencies when `briefcase create`
was first run, the generated Gradle build cache still had references to `PyQt6`.

To clean the old Gradle build cache and re-package with the native Toga Android UI,
run these 3 commands in PowerShell in your `C:\Users\GG\Desktop\Derf` directory:

--------------------------------------------------------------------------------
STEP 1: CLEAN THE OLD BUILD CACHE IN POWERSHELL
--------------------------------------------------------------------------------
Remove-Item -Recurse -Force build\derf\android

--------------------------------------------------------------------------------
STEP 2: RE-CREATE THE FRESH ANDROID PROJECT
--------------------------------------------------------------------------------
briefcase create android

--------------------------------------------------------------------------------
STEP 3: RUN DIRECTLY ON YOUR CONNECTED PHONE
--------------------------------------------------------------------------------
briefcase run android -d f6951a59

================================================================================
SUMMARY OF WHAT WAS FIXED IN CODE:
1. `derf_qt_ui.py` and `derf_peek.py` top-level PyQt6 imports were wrapped in
   `try...except (ImportError, ModuleNotFoundError)` so they never raise crashes on Android.
2. `main.py` and `Derf.py` now feature fail-proof Android platform detection (`is_android_device()`)
   and automatically load `derf_mobile_ui.py` (Toga Android Native UI).
3. `pyproject.toml` Android dependencies now specify `toga-android>=0.4.0`.

Once you run the 3 commands above in PowerShell, the app will launch smoothly on your phone!

================================================================================
BEEWARE BRIEFCASE (NATIVE WINDOWS TO ANDROID APK BUILD GUIDE)
100% Pure Windows — No Linux, WSL, Ubuntu, or VirtualBox Required
================================================================================

This guide walks you through packaging Derf PQ Messenger into an Android APK directly
on your Windows PC using BeeWare Briefcase.

--------------------------------------------------------------------------------
STEP 1: PREREQUISITES ON WINDOWS
--------------------------------------------------------------------------------
1. Python 3.10+ (Installed on Windows and added to PATH).
2. Java JDK 17 (Eclipse Temurin or Oracle JDK 17 installer for Windows).
3. Android Studio for Windows (Download from developer.android.com).
   • Open Android Studio -> Tools -> SDK Manager.
   • Ensure "Android SDK Platform-Tools" and "Android SDK Build-Tools" are installed.

--------------------------------------------------------------------------------
STEP 2: INSTALL BEEWARE BRIEFCASE
--------------------------------------------------------------------------------
Open PowerShell or Command Prompt on Windows as Administrator and run:

    pip install briefcase

--------------------------------------------------------------------------------
STEP 3: CREATE / REFRESH THE ANDROID BUILD PROJECT
--------------------------------------------------------------------------------
In PowerShell, navigate to the Derf directory:

    cd C:\Users\GG\Desktop\Derf

Run briefcase create:

    briefcase create android

(Or `briefcase update android -r` if updating dependencies).

--------------------------------------------------------------------------------
STEP 4: BUILD & LOCATE YOUR STANDALONE .APK FILE
--------------------------------------------------------------------------------
Run the build command:

    briefcase build android

• Gradle will compile the Android app and generate the installable `.apk` file at:

    build\derf\android\gradle\app\build\outputs\apk\debug\app-debug.apk

--------------------------------------------------------------------------------
STEP 5: COPY THE .APK TO YOUR DESKTOP / DIST FOLDER
--------------------------------------------------------------------------------
Run this PowerShell command to copy the `.apk` directly to your `dist` folder:

    if (!(Test-Path dist)) { New-Item -ItemType Directory -Path dist }
    Copy-Item "build\derf\android\gradle\app\build\outputs\apk\debug\app-debug.apk" "dist\Derf_PQ_Messenger.apk" -Force

• Your installable `Derf_PQ_Messenger.apk` file is now ready in `dist\Derf_PQ_Messenger.apk`!
  You can transfer this `.apk` file straight to your Android phone and install it.

--------------------------------------------------------------------------------
STEP 6: RUN / TEST ON EMULATOR OR CONNECTED PHONE (OPTIONAL)
--------------------------------------------------------------------------------
To run the app directly on a connected Android phone or Android Studio Emulator:

    briefcase run android

================================================================================
SUMMARY:
• `briefcase build android` compiles the `.apk` under:
  `build\derf\android\gradle\app\build\outputs\apk\debug\app-debug.apk`
• Run the `Copy-Item` PowerShell command above to place it directly in `dist\`.

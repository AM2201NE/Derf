================================================================================
BEEWARE BRIEFCASE (NATIVE WINDOWS TO ANDROID APK BUILD GUIDE)
100% Pure Windows — No Linux, WSL, Ubuntu, or VirtualBox Required
================================================================================

This guide walks you through packaging and real-time live debugging of Derf PQ Messenger
on Android directly from your Windows PC using BeeWare Briefcase.

--------------------------------------------------------------------------------
STEP 1: PREREQUISITES ON WINDOWS
--------------------------------------------------------------------------------
1. Python 3.10+ (Installed on Windows and added to PATH).
2. Java JDK 17 (Eclipse Temurin or Oracle JDK 17 installer for Windows).
3. Android Studio for Windows (Download from developer.android.com).
   • Open Android Studio -> Tools -> SDK Manager.
   • Ensure "Android SDK Platform-Tools" and "Android SDK Build-Tools" are installed.
   • Add `platform-tools` (containing `adb.exe`) to your Windows PATH environment variable
     (typically `C:\Users\<YourUsername>\AppData\Local\Android\Sdk\platform-tools`).

--------------------------------------------------------------------------------
STEP 2: INSTALL BEEWARE BRIEFCASE
--------------------------------------------------------------------------------
Open PowerShell or Command Prompt on Windows as Administrator and run:

    pip install briefcase

--------------------------------------------------------------------------------
STEP 3: CREATE / REFRESH THE ANDROID BUILD PROJECT
--------------------------------------------------------------------------------
In PowerShell, navigate to the Derf directory:

    cd C:\Users\GG\Desktop\Derf

If updating dependencies or code structure in `pyproject.toml` (e.g., adding `toga-android`):

    briefcase update android -r

(Or run `briefcase create android` if initializing for the first time).

--------------------------------------------------------------------------------
STEP 4: BUILD & LOCATE YOUR STANDALONE .APK FILE
--------------------------------------------------------------------------------
Run the build command:

    briefcase build android

• Gradle will compile the Android app and generate the installable `.apk` file at:

    build\derf\android\gradle\app\build\outputs\apk\debug\app-debug.apk

--------------------------------------------------------------------------------
STEP 5: COPY THE .APK TO YOUR DESKTOP / DIST FOLDER (FOR DISTRIBUTION)
--------------------------------------------------------------------------------
Run this PowerShell command to copy the `.apk` directly to your `dist` folder:

    if (!(Test-Path dist)) { New-Item -ItemType Directory -Path dist }
    Copy-Item "build\derf\android\gradle\app\build\outputs\apk\debug\app-debug.apk" "dist\Derf_PQ_Messenger.apk" -Force

• Your installable `Derf_PQ_Messenger.apk` file is now ready in `dist\Derf_PQ_Messenger.apk`!

--------------------------------------------------------------------------------
STEP 6: REAL-TIME DIRECT DEBUG TRIAL ON ANDROID (WITHOUT MOVING APK FILES)
--------------------------------------------------------------------------------
To test and debug the app directly on a physical Android phone or Emulator in real time
without needing to manually copy or install `.apk` files:

1. Enable Developer Options & USB Debugging on your Android Phone:
   • Go to Settings -> About Phone -> tap "Build Number" 7 times.
   • Go to System -> Developer Options -> turn ON "USB Debugging".
   • Connect your phone to your PC via USB cable and tap "Allow USB Debugging" on phone.

2. Verify connected Android device in PowerShell:

    adb devices

   (You should see your phone listed, e.g., `f6951a59  device`).

3. Refresh dependencies and re-launch directly on your phone:

    briefcase update android -r
    briefcase run android -d f6951a59

   Briefcase will automatically compile, push, install, launch the app on your phone,
   and stream live terminal logs directly to your Windows PowerShell prompt.

4. Quick Code Iteration / Fast Refresh (No full recompile needed):
   If you edit any Python code (e.g. `Derf.py`, `derf_mobile_ui.py`) and want to instantly
   update and test on the phone without re-building Gradle:

    briefcase run android -u -d f6951a59

   The `-u` (update) flag syncs Python code changes directly to the app bundle on the phone
   and restarts the app immediately.

--------------------------------------------------------------------------------
STEP 7: REAL-TIME CRASH & LOG MONITORING (ADB LOGCAT)
--------------------------------------------------------------------------------
If the app closes or crashes on Android launch, capture live Python stack traces instantly:

Open a separate PowerShell window and run:

    adb logcat *:S python:V stdio:V AndroidRuntime:E

This streams live stdout, stderr, Python tracebacks, and Android crash exceptions directly
to your screen in real time so you can inspect and fix any issues instantly!

================================================================================
SUMMARY OF DEBUG COMMANDS:
• Refresh dependencies & build:   `briefcase update android -r`
• Direct live trial on phone:     `briefcase run android -d f6951a59`
• Sync code & re-launch on phone: `briefcase run android -u -d f6951a59`
• Live log & exception stream:     `adb logcat *:S python:V stdio:V AndroidRuntime:E`

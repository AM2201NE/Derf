================================================================================
OPTIONS FOR PACKAGING DERF / PYTHON APPS AS APK ON NATIVE WINDOWS
(100% Pure Windows — No WSL, Ubuntu, Dual-Boot, or VirtualBox Required)
================================================================================

If you are running Windows and want to build an Android APK without installing Linux,
WSL2, Ubuntu, or VirtualBox, here are your best, fully functional options:

--------------------------------------------------------------------------------
OPTION 1: GitHub Actions CI/CD Cloud Build (RECOMMENDED & MOST POPULAR)
--------------------------------------------------------------------------------
• How it works:
  You keep working on native Windows. Whenever you push code to GitHub (or click
  "Run Workflow"), GitHub's cloud Linux runner automatically compiles your Python app,
  runs Buildozer/Kivy/PyQt, builds the signed `.apk` file, and attaches it as a downloadable
  release artifact right in your browser.

• Why it's the best option for native Windows users:
  1. Zero Linux setup on your PC (100% pure Windows development).
  2. Free cloud compilation provided by GitHub.
  3. You simply download `app-debug.apk` directly from GitHub onto your Windows PC
     or phone.

• Setup Steps:
  1. Create a `.github/workflows/android.yml` file in your repository.
  2. Push your repo to GitHub.
  3. Download the generated `.apk` under the "Actions" tab on GitHub.

--------------------------------------------------------------------------------
OPTION 2: BeeWare Briefcase (Native Windows Build System)
--------------------------------------------------------------------------------
• How it works:
  BeeWare (`briefcase`) is a Python framework designed to build native mobile
  and desktop apps directly on Windows. Briefcase supports generating Android Studio /
  Gradle projects natively on Windows using the official Android SDK and NDK.

• Commands on Windows PowerShell / Command Prompt:
  1. `pip install briefcase`
  2. `briefcase new` (or configure `pyproject.toml`)
  3. `briefcase create android`
  4. `briefcase build android`
  5. `briefcase package android` (generates `.apk` or `.aab`)

• Requirements:
  • Official Android Studio & Java JDK installed on Windows (standard Windows installers).

--------------------------------------------------------------------------------
OPTION 3: Chaquopy + Android Studio (Native Windows Gradle Plugin)
--------------------------------------------------------------------------------
• How it works:
  Chaquopy is a Python plugin for standard Android Gradle builds. You open Android Studio
  on Windows, create a standard Android Java/Kotlin project shell, and configure Chaquopy
  in `build.gradle.kts`. When you click "Build APK" in Android Studio on Windows,
  Chaquopy embeds Python into the APK.

• Advantage:
  • Runs 100% natively in Windows Android Studio.
  • Full access to Android native APIs and UI components.

--------------------------------------------------------------------------------
OPTION 4: Qt Creator + Android NDK on Windows (For PyQt / PySide Apps)
--------------------------------------------------------------------------------
• How it works:
  Using Qt Creator for Windows with the Windows Android NDK (r25+) and JDK 17,
  Qt Creator compiles PyQt6 / PySide6 applications into Android APKs natively on Windows.

• Setup Requirements:
  1. Install Qt Creator for Windows.
  2. Install Android Studio / Android Command-line Tools for Windows.
  3. Download Windows Android NDK (r25b+).
  4. Configure Qt Creator: Devices -> Android -> Set SDK & NDK paths.
  5. Click "Build APK".

--------------------------------------------------------------------------------
OPTION 5: Online Cloud APK Builders & Docker Desktop for Windows
--------------------------------------------------------------------------------
• Docker Desktop for Windows (Hyper-V / Windows Containers):
  If you have Docker Desktop installed on Windows, you can run a single container command:
  `docker run -v C:\Users\GG\Desktop\Derf:/home/user/hostapp kivy/buildozer`
  This builds the APK in the background and saves the `.apk` straight to your Windows Desktop.

================================================================================
SUMMARY & RECOMMENDATION:
• For zero-installation effortless builds: Option 1 (GitHub Actions Cloud Build).
• For 100% offline native Windows builds: Option 2 (BeeWare Briefcase) or Option 3 (Chaquopy + Android Studio).

================================================================================
ANDROID HIGH-PERFORMANCE UI FRAMEWORKS & PYTHON BACKEND ARCHITECTURE GUIDE
================================================================================

If BeeWare Toga feels UI-limited, this guide breaks down the top high-performance,
world-class UI technologies for Android that seamlessly integrate with your existing
Derf Python post-quantum cryptographic backend (`Derf.py`).

--------------------------------------------------------------------------------
OPTION 1: KOTLIN + JETPACK COMPOSE (Google's Native Android UI Standard)
--------------------------------------------------------------------------------
• Language / Tech: Kotlin + Jetpack Compose (Declarative UI)
• UI Quality & Performance: ⭐⭐⭐⭐⭐ (100% Native 120Hz GPU Rendering)
• Design System: Material Design 3 (Material You), smooth animations, native gestures,
  system dark mode, dynamic themes, native context menus, and accessibility.

• How it connects with Python (`Derf.py`):
  1. Chaquopy Gradle Plugin: Embeds your Python scripts (`Derf.py`) directly into
     a standard Android Studio Kotlin project.
  2. Calling Python from Kotlin:
     val py = Python.getInstance()
     val derfModule = py.getModule("Derf")
     val ciphertext = derfModule.callAttr("encrypt_alien_stack", message, peer, identity).toString()
  3. Benefits: Zero IPC overhead, direct access to Android Accessibility Services,
     notifications, native clipboards, and 60/120 FPS hardware-accelerated animations.

--------------------------------------------------------------------------------
OPTION 2: FLUTTER (Dart + C-ABI / HTTP Bridge)
--------------------------------------------------------------------------------
• Language / Tech: Dart (Flutter Engine)
• UI Quality & Performance: ⭐⭐⭐⭐⭐ (Custom Skia/Impeller 120 FPS Graphics Engine)
• Design System: World-class custom UI, iOS Cupertinowidgets, Material 3, glassmorphism,
  custom animations, custom shaders, and pixel-perfect responsive layouts on mobile & desktop.

• How it connects with Python (`Derf.py`):
  1. Embedded Python via CFFI / C-ABI: Compile Python as a shared library (`libpython.so`)
     and call core functions via Flutter `dart:ffi`.
  2. Local Loopback Socket / HTTP API: Run `Derf.py` as a lightweight background daemon
     listening on `127.0.0.1:5000` (FastAPI / HTTP / WebSockets). Flutter UI sends JSON
     requests to encrypt/decrypt and receives results instantly.
  3. Benefits: Cross-platform code sharing (iOS, Android, Windows, macOS) with identical
     pixel-perfect UI across all devices.

--------------------------------------------------------------------------------
OPTION 3: REACT NATIVE (TypeScript / JavaScript + Python Bridge)
--------------------------------------------------------------------------------
• Language / Tech: TypeScript / JavaScript (React Native / Expo)
• UI Quality & Performance: ⭐⭐⭐⭐☆ (Native iOS/Android UI Components)
• Design System: Tailwind CSS (NativeWind), Animated API, React Native Paper,
  sleek mobile UI libraries, bottom sheets, gesture handlers, and fluid transitions.

• How it connects with Python (`Derf.py`):
  1. Native JSI Bridge: Expose Python C-API functions directly to React Native JavaScript engine.
  2. Local HTTP / WebSocket Daemon: React Native frontend communicates with local Python
     service on `localhost` via Axios or WebSocket connections.
  3. Benefits: Massive UI component ecosystem, rapid UI development, web/mobile reuse.

--------------------------------------------------------------------------------
OPTION 4: PYSIDE6 / PYQT6 FOR ANDROID (Qt Creator + Android NDK)
--------------------------------------------------------------------------------
• Language / Tech: Python + Qt QML / C++ Qt
• UI Quality & Performance: ⭐⭐⭐⭐☆ (Hardware-Accelerated QML Scene Graph)
• Design System: Qt Quick Controls, custom GPU shaders, fluid dark themes, animations,
  glassmorphism, and desktop/mobile responsiveness.

• How it connects with Python (`Derf.py`):
  1. Native Python Integration: Runs your exact PyQt6 / PySide6 code directly on Android using
     Qt Creator and the official Android NDK.
  2. Benefits: 100% same codebase for Windows desktop GUI (`derf_qt_ui.py`) and Android mobile UI!

--------------------------------------------------------------------------------
RECOMMENDATION SUMMARY FOR DERF:
1. For maximum Android UI perfection, native gestures, and accessibility:
   -> Kotlin + Jetpack Compose with Chaquopy (Option 1).
2. For cross-platform (iOS + Android + Desktop) visual beauty:
   -> Flutter with Local Loopback Daemon or Dart FFI (Option 2).
3. For keeping 100% Python codebase across PC and Mobile:
   -> PySide6 / Qt QML for Android (Option 4).

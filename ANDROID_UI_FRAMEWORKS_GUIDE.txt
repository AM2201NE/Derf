100% SERVERLESS, DIRECT IN-PROCESS ANDROID UI SOLUTIONS FOR DERF
================================================================================

This guide focuses EXCLUSIVELY on direct, serverless, in-process frameworks for Android
that call your existing Python post-quantum cryptographic backend (`Derf.py`) directly
in memory—with ZERO web servers, ZERO background daemons, and ZERO network IPC.

--------------------------------------------------------------------------------
OPTION 1: PYSIDE6 / PYQT6 FOR ANDROID (EASIEST — 100% TOOL PARITY WITH PC)
--------------------------------------------------------------------------------
• Tech: Python + PySide6 / PyQt6 + Qt Creator (Android NDK)
• Serverless: YES (100% Direct In-Memory Python Execution)
• Effort Level: LOWEST (Use your exact same `derf_qt_ui.py` PC code!)
• Tool Parity with PC: 100% Identical. You use the exact same PyQt6 widgets, QML,
  Qt Designer, stylesheets, layout managers, and Python libraries as on Windows PC.

• How it Works on Android:
  Qt Creator compiles PyQt6 / PySide6 directly into an Android APK natively on Windows.
  Your `derf_qt_ui.py` script runs in the exact same Python process in memory on Android
  as it does on PC.

  Example in Python (Direct In-Memory Call):
      import Derf
      ciphertext = Derf.encrypt_alien_stack(message, peer, identity)

--------------------------------------------------------------------------------
OPTION 2: KOTLIN + JETPACK COMPOSE WITH CHAQUOPY (RECOMMENDED FOR NATIVE ANDROID)
--------------------------------------------------------------------------------
• Tech: Kotlin + Jetpack Compose + Chaquopy
• Serverless: YES (Direct In-Process C-API / JNI Calls)
• Effort Level: LOW (Declarative UI in Kotlin, Python runs in-process)
• Tool Parity: Full access to all Android Studio visual preview tools, layout inspectors,
  Kotlin coroutines, and Material 3 design components.

• How it Works on Android:
  Chaquopy runs the Python interpreter inside the main Android APK process space.
  Kotlin calls `Derf.py` functions directly in memory via C-API bindings—NO network required.

  Example in Kotlin (Direct In-Process Call):
      val py = Python.getInstance()
      val derf = py.getModule("Derf")
      val ciphertext = derf.callAttr("encrypt_alien_stack", msg, peer, idn).toString()

--------------------------------------------------------------------------------
OPTION 3: KIVY / KIVYMD FOR ANDROID (100% PYTHON & NO JAVA REQUIRED)
--------------------------------------------------------------------------------
• Tech: Python + Kivy / KivyMD + Buildozer
• Serverless: YES (100% Direct In-Process Python)
• Effort Level: LOW (100% Python codebase, custom UI widgets)
• Tool Parity: Uses standard Python IDEs (VS Code / PyCharm).

• How it Works on Android:
  Kivy packages Python and SDL2 graphics into an Android APK. All UI code is written
  in pure Python and KV language, calling `Derf.py` functions directly in memory.
